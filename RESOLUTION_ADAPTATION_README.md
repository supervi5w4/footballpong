# Система адаптивного разрешения для Football Pong

## Описание проблемы
Ранее все позиции поля и стен в `scenes/game.tscn` были заданы абсолютными координатами для экрана 1920×1080, что приводило к тому, что часть игрового поля не попадала в кадр на других устройствах.

## Решение
Добавлена система динамического позиционирования, которая:
1. Вычисляет масштаб на основе текущего размера viewport
2. Позиционирует все элементы поля относительно центра экрана
3. Адаптируется к изменениям размера окна в реальном времени

## Основные изменения

### 1. `scenes/game.gd`
Добавлены новые функции:
- `_calculate_viewport_scale()` - вычисляет масштаб для адаптации
- `_position_field_elements()` - позиционирует все элементы поля
- `_position_walls()` - позиционирует стены
- `_scale_position()` - масштабирует позиции относительно центра
- `get_field_bounds()` - возвращает границы игрового поля
- `get_goal_positions()` - возвращает позиции ворот
- `get_spawn_position()` - возвращает позицию спавна мяча

### 2. `scenes/player_paddle.gd`
Добавлен метод:
- `set_start_position(pos: Vector2)` - устанавливает новую стартовую позицию

### 3. `scenes/ai_paddle.gd`
Добавлен метод:
- `set_start_position(pos: Vector2)` - устанавливает новую стартовую позицию

### 4. `scenes/ball.gd`
Обновлен метод `_find_spawn()` для использования динамической позиции спавна

## Константы позиционирования
Все базовые координаты вынесены в константы в начале `game.gd`:
```gdscript
const BASE_FIELD_POSITION := Vector2(962, 533)
const BASE_FIELD_SCALE := Vector2(1.25651, 1.14258)
const BASE_WALL_TOP_POS := Vector2(956, 132)
# ... и другие
```

## Как это работает

### 1. Вычисление масштаба
```gdscript
var base_size = Vector2(1920, 1080)
_scale_factor.x = _viewport_size.x / base_size.x
_scale_factor.y = _viewport_size.y / base_size.y
```

### 2. Масштабирование позиций
```gdscript
func _scale_position(base_position: Vector2) -> Vector2:
    var viewport_center = _viewport_size * 0.5
    var base_center = Vector2(1920, 1080) * 0.5
    var offset = base_position - base_center
    var scaled_offset = offset * _scale_factor
    return viewport_center + scaled_offset
```

### 3. Обработка изменения размера окна
```gdscript
func _notification(what: int) -> void:
    if what == NOTIFICATION_WM_SIZE_CHANGED:
        _calculate_viewport_scale()
        _position_field_elements()
```

## Тестирование

### Тестовая сцена
Создана тестовая сцена `test_resolution.tscn` для проверки системы:
- Запустите сцену
- Измените размер окна
- Нажмите `R` для пересчета позиций
- Нажмите `I` для вывода информации о поле

### Проверка на разных разрешениях
1. Запустите игру в полноэкранном режиме
2. Измените разрешение экрана
3. Убедитесь, что все элементы остаются в пределах видимой области
4. Проверьте, что мяч и ракетки корректно ограничены границами поля

## Совместимость
- Система полностью совместима с существующим кодом
- Не влияет на игровую логику
- Работает как в обычном режиме, так и в турнирном
- Поддерживает все существующие функции

## Производительность
- Вычисления выполняются только при инициализации и изменении размера окна
- Не влияет на производительность во время игры
- Минимальные накладные расходы
