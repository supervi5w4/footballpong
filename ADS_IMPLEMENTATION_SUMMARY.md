# Резюме изменений системы рекламы

## Выполненные изменения

### 1. Удаление рекламы при голе (`scenes/goal.gd`)
- ✅ Удален вызов `YandexSDK.show_interstitial_on_goal()` из метода `_on_body_entered`
- ✅ Реклама больше не показывается при забивании голов в быстрой игре

### 2. Удаление рекламы из меню (`scenes/menu.gd`)
- ✅ Удалены вызовы `YandexSDK.show_interstitial_ad()` из методов:
  - `_on_play_pressed()` - при переходе к быстрой игре
  - `_on_tournament_pressed()` - при переходе к турниру
- ✅ Убрано ожидание завершения рекламы (`await YandexSDK.interstitial_ad`)

### 3. Добавление рекламы в турнир (`scenes/tournament_controller.gd`)
- ✅ В методе `_finalize_match()` добавлен показ рекламы между матчами:
  ```gdscript
  if YandexSDK.is_working():
      YandexSDK.show_interstitial_between_matches()
      await YandexSDK.interstitial_ad
  ```
- ✅ Реклама показывается только после завершения каждого турнирного матча

### 4. Счетчик рекламы (`score_manager.gd`)
- ✅ Заменена переменная `ad_shown: bool` на `ads_shown_count: int = 0`
- ✅ Счетчик отслеживает количество показанных реклам

### 5. Увеличение счетчика (`addons/yandex_games_sdk/yandex_sdk.gd`)
- ✅ В методе `show_interstitial_ad()` добавлено увеличение счетчика:
  ```gdscript
  if Score:
      Score.ads_shown_count += 1
  ```

## Результат

### Быстрая игра
- ❌ Реклама полностью убрана
- ❌ Не показывается при голе
- ❌ Не показывается при запуске

### Турнирный режим
- ✅ Реклама показывается один раз после каждого матча
- ✅ Ожидание завершения рекламы перед переходом к календарю
- ✅ Счетчик `Score.ads_shown_count` увеличивается при каждом показе

### Отладка
- ✅ Создан тестовый файл `test_ads_counter.gd` для проверки работы
- ✅ Счетчик доступен через `Score.ads_shown_count` в любом месте игры

## Проверка работы

1. Запустите быструю игру - реклама не должна появляться
2. Запустите турнир - реклама должна появляться после каждого матча
3. Проверьте счетчик: `print(Score.ads_shown_count)`
