# ⏱️ Табло времени для Football Pong

## 📋 Описание

Реализация табло времени для футбольного матча с ускорением времени в 180 раз. Время отображается в формате MM:SS с указанием текущего тайма.

## ✅ Реализованные функции

### 1. Таймер матча (`scripts/match_timer.gd`)
- **Ускорение времени**: 15 секунд реального времени = 45 минут игрового времени
- **Два тайма**: Первый (0-45 мин) и второй (45-90 мин)
- **Плавное обновление**: Время обновляется каждую секунду
- **Сигналы**: `time_updated`, `period_changed`, `match_ended`

### 2. Табло времени (`scripts/time_scoreboard.gd`)
- **Визуальное отображение**: Время в формате MM:SS
- **Номер тайма**: Отображение текущего периода (1 или 2)
- **Интеграция с таймером**: Автоматическое обновление

### 3. Интеграция в игру
- **Обычный матч**: Табло времени добавлено в `scenes/game.tscn`
- **Турнир**: Табло времени интегрировано в турнирную логику
- **Автозапуск**: Таймер запускается автоматически при старте матча

## 🔧 Техническая реализация

### Константы таймера
```gdscript
const REAL_SECONDS_PER_PERIOD: float = 15.0  # 15 секунд реального времени на тайм
const GAME_MINUTES_PER_PERIOD: int = 45      # 45 минут игрового времени на тайм
const SPEED_MULTIPLIER: float = GAME_MINUTES_PER_PERIOD / REAL_SECONDS_PER_PERIOD  # 180x
```

### Основные методы таймера
```gdscript
func start_match() -> void      # Запуск матча
func pause_match() -> void      # Пауза матча
func resume_match() -> void     # Возобновление матча
func stop_match() -> void       # Остановка матча
func reset_match() -> void      # Сброс матча
func get_time_string() -> String # Получение времени в формате MM:SS
```

### Сигналы таймера
```gdscript
signal time_updated(minutes: int, seconds: int, period: int)
signal period_changed(period: int)
signal match_ended()
```

## 🎯 Точки интеграции

### 1. Игровая сцена (`scenes/game.gd`)
```gdscript
@onready var time_scoreboard: TimeScoreboard = $UI/TimeScoreboard

func _ready() -> void:
	# Запускаем таймер матча
	if time_scoreboard:
		time_scoreboard.start_match()

func _exit_tree() -> void:
	# Останавливаем таймер матча
	if time_scoreboard:
		time_scoreboard.stop_match()
```

### 2. Турнирная игра (`scenes/tournament_game.gd`)
```gdscript
@onready var time_scoreboard: TimeScoreboard = game_node.get_node("UI/TimeScoreboard") as TimeScoreboard
var match_timer: MatchTimer

func _ready() -> void:
	# Инициализация таймера матча
	if time_scoreboard:
		match_timer = time_scoreboard.get_match_timer()
		if match_timer:
			match_timer.period_changed.connect(_on_period_changed)
			match_timer.match_ended.connect(_on_match_ended)
```

## 📊 Логика времени

### Ускорение времени
- **Реальное время**: 15 секунд на тайм
- **Игровое время**: 45 минут на тайм
- **Множитель**: 180x ускорение

### Отображение времени
- **Формат**: MM:SS (например, 23:45)
- **Тайм 1**: 00:00 - 45:00
- **Тайм 2**: 45:00 - 90:00

### Смена периодов
- **Автоматическая**: При достижении 45 минут
- **Сигнал**: `period_changed` отправляется при смене тайма
- **Логирование**: В консоль выводится информация о смене периодов

## 🎮 Использование

### В обычном матче
1. Табло времени автоматически запускается при старте игры
2. Время отображается в правой части экрана рядом с табло счета
3. Таймер работает независимо от гола и сброса раунда

### В турнире
1. Таймер интегрирован с турнирной логикой
2. Смена таймов синхронизирована с таймером
3. Окончание матча определяется по таймеру
