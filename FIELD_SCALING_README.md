# Система масштабирования поля

## Описание

Реализована система автоматического масштабирования поля, которая адаптирует размер спрайта поля к различным разрешениям экрана, сохраняя пропорции и обеспечивая полную видимость поля.

## Компоненты

### 1. FieldController (`scenes/field_controller.gd`)

Основной контроллер для управления масштабированием поля.

**Основные функции:**
- Автоматическое вычисление оптимального масштаба на основе размера viewport
- Позиционирование поля в центре экрана
- Обработка изменений размера окна
- Предоставление информации о границах поля

**Ключевые методы:**
- `set_field_sprite(sprite: Sprite2D)` - устанавливает спрайт поля для управления
- `get_field_scale()` - возвращает текущий масштаб поля
- `get_field_bounds()` - возвращает границы поля в мировых координатах
- `is_field_visible()` - проверяет, полностью ли поле видимо на экране

**Сигналы:**
- `field_scaled(new_scale: Vector2, new_position: Vector2)` - отправляется при изменении масштаба поля

### 2. Обновленный Game.gd

Интегрирован с FieldController для автоматического управления масштабированием.

**Изменения:**
- Удалена ручная логика масштабирования поля
- Добавлена интеграция с FieldController
- Поле теперь автоматически масштабируется при запуске и изменении размера окна

## Как это работает

1. **Инициализация:**
   - При запуске игры FieldController получает размер текстуры поля
   - Вычисляется доступное пространство на экране (с учетом отступов)
   - Определяется оптимальный масштаб для сохранения пропорций

2. **Масштабирование:**
   - Поле позиционируется в центре viewport
   - Применяется вычисленный масштаб к спрайту поля
   - Отправляется сигнал `field_scaled` для уведомления других компонентов

3. **Адаптация к изменениям:**
   - При изменении размера окна автоматически пересчитывается масштаб
   - Поле остается полностью видимым на любом разрешении

## Константы настройки

В `FieldController` можно настроить:

```gdscript
const MIN_MARGIN := 50.0  # Минимальный отступ от краев экрана
const ASPECT_RATIO_TOLERANCE := 0.1  # Допустимое отклонение от пропорций
```

## Использование

### Базовое использование

```gdscript
# В сцене игры
@onready var field_controller: FieldController = $FieldController
@onready var field: Sprite2D = $Field

func _ready():
    field_controller.set_field_sprite(field)
    field_controller.field_scaled.connect(_on_field_scaled)

func _on_field_scaled(new_scale: Vector2, new_position: Vector2):
    print("Поле масштабировано: ", new_scale)
```

### Получение информации о поле

```gdscript
# Получить текущий масштаб
var scale = field_controller.get_field_scale()

# Получить границы поля
var bounds = field_controller.get_field_bounds()

# Проверить видимость
var is_visible = field_controller.is_field_visible()
```

- Проверяет корректность масштабирования

- Выводит подробную информацию о состоянии системы

## Преимущества

1. **Автоматическая адаптация** - поле автоматически подстраивается под любое разрешение
2. **Сохранение пропорций** - поле не искажается при масштабировании
3. **Полная видимость** - поле всегда остается полностью видимым на экране
4. **Модульность** - система легко интегрируется в другие сцены
5. **Отзывчивость** - автоматически реагирует на изменения размера окна

## Совместимость

Система совместима с:
- Различными разрешениями экрана
- Изменением размера окна во время игры
- Существующими компонентами игры (ракетки, мяч, стены)

## Устранение неполадок

### Поле не масштабируется
1. Проверьте, что FieldController добавлен в сцену
2. Убедитесь, что спрайт поля имеет текстуру
3. Проверьте консоль на наличие ошибок

### Поле выходит за границы экрана
1. Увеличьте значение `MIN_MARGIN` в FieldController
2. Проверьте размер текстуры поля
3. Убедитесь, что viewport правильно инициализирован

### Проблемы с производительностью
1. Система оптимизирована и не должна вызывать проблем
2. Масштабирование происходит только при изменении размера окна
3. При необходимости можно добавить дебаунсинг для частых изменений размера
