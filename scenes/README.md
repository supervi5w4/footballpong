# Сцены турнира - README

## Обновления финальной сцены и календаря турнира

### Финальная таблица (final_table.gd, final_table.tscn)

**Структура:**
- CenterContainer → PanelContainer → ScrollContainer → VBoxContainer
- Все элементы центрированы
- Ограниченная высота ScrollContainer (400px) с вертикальной прокруткой

**Функциональность:**
- Константы для настройки (FONT_SIZE, PADDING, MIN_PANEL_SIZE)
- Подсветка топ-3 команд (золото, серебро, бронза)
- Обрезка длинных имен команд с "..."
- Сообщения о местах: "Поздравляем — вы заняли N-е место!"
- Кнопки: "В меню" (с подтверждением) и "Replay" (сброс результатов)

**Визуальные улучшения:**
- Единый шрифт PressStart2P-Regular.ttf через theme_override
- Центрирование всех текстовых элементов
- Фиксированные размеры ячеек таблицы

### Календарь турнира (tournament_calendar.gd, tournament_calendar.tscn)

**Структура календаря:**
- Каждая панель тура обернута в CenterContainer
- custom_minimum_size для надежного вертикального центрирования
- Все тексты центрированы по горизонтали и вертикали

**Функциональность:**
- Константы для настройки интерфейса
- Подсветка топ-3 в таблице команд
- Lazy-render для больших таблиц (>16 команд)
- Улучшенная сортировка команд

**Визуальные улучшения:**
- Единый шрифт через theme_override на root
- Автоматическая обрезка длинных имен
- Улучшенное центрирование элементов

### Константы для настройки

```gdscript
const FONT_SIZE : int = 16
const PADDING : int = 20
const MIN_PANEL_SIZE : Vector2 = Vector2(190, 250)
const MAX_TEAMS_FOR_LAZY_RENDER : int = 16
```

const GOLD_COLOR : Color = Color(1.0, 0.84, 0.0, 1.0)    # #FFD700
