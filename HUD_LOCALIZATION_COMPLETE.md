## Рекомендации для будущего

### 1. При добавлении новых UI элементов:
```gdscript
// ✅ Правильно:
score_label.text = tr("Счёт: {v}").format({"v": score})
time_label.text = tr("Время: {m}:{s}").format({"m": mm, "s": ss})
period_label.text = tr("Первый тайм")

// ❌ Неправильно:
score_label.text = "Счёт: " + str(score)
time_label.text = "Время: " + str(m) + ":" + str(s)
```

### 2. Единый стиль плейсхолдеров:
- `{v}` - общие значения
- `{m}`, `{s}` - минуты, секунды
- `{n}` - номера
- `{team}` - названия команд
- `{gf}`, `{ga}` - голы забитые/пропущенные

### 3. Существующие ключи покрывают:
