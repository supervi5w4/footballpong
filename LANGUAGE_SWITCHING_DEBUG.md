# Диагностика проблемы с переключением языка

## Проблема
Кнопка переключения языка добавлена, но язык не переключается.

## Выполненные диагностические шаги

### 1. Проверка LocaleManager
- ✅ LocaleManager добавлен в Autoload
- ✅ Файл `i18n/locale_manager.gd` существует и корректен
- ✅ Добавлены отладочные сообщения для отслеживания работы

### 2. Проверка файлов переводов
- ✅ Файлы `locale.en.translation` и `locale.ru.translation` существуют
- ✅ Файлы пересозданы из `.txt` версий
- ✅ CSV файл `locale.csv` содержит все необходимые ключи

### 3. Проверка project.godot
- ✅ Секция `[locale]` настроена правильно
- ✅ Переводы указаны в `translations` массиве
- ✅ Fallbacks настроены

### 4. Улучшения в коде

#### Обновлен скрипт меню (`scenes/menu.gd`):
```gdscript
func _on_lang_button_pressed() -> void:
	var cur := TranslationServer.get_locale()
	var next := "ru" if cur == "en" else "en"
	var locale_manager = get_node("/root/LocaleManager")
	if locale_manager:
		locale_manager.set_lang(next)
		print("Переключен язык с ", cur, " на ", next)
		# Обновляем текст кнопки после смены языка
		_update_lang_button_text()
		# Принудительно обновляем все элементы меню
		locale_manager.translate_tree(self)
	else:
		print("❌ LocaleManager не найден!")
```

#### Улучшен LocaleManager (`i18n/locale_manager.gd`):
```gdscript
func set_lang(lang: String) -> void:
	print("LocaleManager: переключаем на язык ", lang)
	TranslationServer.set_locale(lang)
	print("LocaleManager: локаль установлена на ", TranslationServer.get_locale())
	translate_tree(get_tree().root)
	print("LocaleManager: дерево переведено")
```

## Возможные причины проблемы

### 1. Проблемы с импортом файлов переводов
- Файлы переводов могут быть в неправильном формате
- Godot может не загружать их корректно

### 2. Проблемы с LocaleManager
- Синглтон может не инициализироваться правильно
- Функция `translate_tree` может не работать как ожидается

### 3. Проблемы с UI элементами
- Элементы могут не обновляться после перевода
- Кнопка может не получать сигналы

## Альтернативные решения

### Если проблема в LocaleManager:
- Использовать прямое переключение через `TranslationServer.set_locale()`
- Обновлять элементы вручную после смены языка

### Если проблема в файлах переводов:
- Пересоздать файлы переводов через Godot Editor
- Использовать CSV импорт вместо ручных файлов

### Если проблема в UI:
- Принудительно обновлять все элементы после смены языка
- Использовать сигналы для уведомления о смене языка
