# Реализация кнопки переключения языка

## Выполненные изменения

### 1. Добавлена кнопка в сцену меню

**Файл**: `scenes/menu.tscn`

```gdscript
[node name="LangButton" type="Button" parent="."]
unique_name_in_owner = true
layout_mode = 1
anchors_preset = 1
anchor_left = 1.0
anchor_right = 1.0
offset_left = -120.0
offset_top = 20.0
offset_right = -20.0
offset_bottom = 60.0
grow_horizontal = 0
theme_override_fonts/font = ExtResource("1_vjb58")
theme_override_font_sizes/font_size = 16
text = "EN / RU"
```

**Характеристики кнопки:**
- Расположение: правый верхний угол (top-right)
- Размер: 100x40 пикселей
- Шрифт: PressStart2P (как у остальных кнопок)
- Размер шрифта: 16px
- Уникальное имя: `LangButton`

### 2. Обновлен скрипт меню

**Файл**: `scenes/menu.gd`

#### Добавлены переменные:
```gdscript
@onready var lang_btn : Button = %LangButton     # Кнопка переключения языка
```

#### Подключен сигнал:
```gdscript
lang_btn.pressed.connect(_on_lang_button_pressed)
```

#### Добавлены функции:
```gdscript
func _on_lang_button_pressed() -> void:
	var cur := TranslationServer.get_locale()
	var next := "ru" if cur == "en" else "en"
	var locale_manager = get_node("/root/LocaleManager")
	if locale_manager:
		locale_manager.set_lang(next)
		print("Переключен язык с ", cur, " на ", next)
		# Обновляем текст кнопки после смены языка
		_update_lang_button_text()

func _update_lang_button_text() -> void:
	var current_lang := TranslationServer.get_locale()
	# Показываем противоположный язык (что будет при нажатии)
	var button_text := "RU" if current_lang == "en" else "EN"
	lang_btn.text = button_text
```

## Логика работы

### Переключение языка:
1. При нажатии кнопки определяется текущий язык
2. Вычисляется следующий язык (en ↔ ru)
3. Вызывается `LocaleManager.set_lang(next)`
4. Обновляется текст кнопки

### Отображение текста кнопки:
- Если интерфейс на английском → кнопка показывает "RU"
- Если интерфейс на русском → кнопка показывает "EN"

Это интуитивно понятно: кнопка показывает, на какой язык можно переключиться.

## Интеграция с LocaleManager

Кнопка полностью интегрирована с существующей системой локализации:
- Использует `LocaleManager.set_lang()` для переключения
- Автоматически обновляет все UI элементы через `translate_tree()`
- Работает с существующими файлами переводов
- Поддерживает автоопределение языка браузера
