# Исправление проблемы с жёстко заданными размерами игрового поля в ИИ

## Проблема
Скрипт `scenes/ai_paddle.gd` использовал жёстко заданные константы `Vector2(1920, 1080)` для размеров поля и координат ворот, что приводило к выходу объектов за границы при других разрешениях.

## Исправления

### 1. Удалены жёстко заданные константы
- Удалена константа `FIELD_SIZE: Vector2i = Vector2i(1920, 1080)`
- Удалена константа `HALF_FIELD_X: int = FIELD_SIZE.x / 2`
- Удалена переменная `goal_right: Vector2 = Vector2(1920, 540)`

### 2. Добавлены динамические методы
```gdscript
func get_field_size() -> Vector2:
    """Возвращает текущий размер игрового поля из viewport"""
    return get_viewport_rect().size

func get_half_field_x() -> float:
    """Возвращает координату X центра поля"""
    return get_field_size().x * 0.5

func get_goal_right() -> Vector2:
    """Возвращает позицию правых ворот"""
    var field_size = get_field_size()
    return Vector2(field_size.x, field_size.y * 0.5)
```

### 3. Обновлены все места использования
- `_check_first_hit_reset()` - использует `get_half_field_x()`
- `_think()` - использует `get_field_size()` для проверки границ
- `_goal_pos()` - использует `get_goal_right()`
- `_attack_pos()` - использует `get_goal_right()`
- `_block_pos()` - использует `get_field_size()`
- `_edge_guard_pos()` - использует `get_field_size()`
- `_predict_second_bounce()` - использует `get_field_size()`
- `_predict_multi_bounce()` - использует `get_field_size()`
- `_is_on_my_side()` - использует `get_half_field_x()`
- `_predict_intercept()` - использует `get_field_size()`
- `_dodge_pos()` - использует `get_field_size()`
- `_retreat_pos()` - использует `get_goal_right()`
- `_clamp_advancement()` - использует `get_field_size()`
